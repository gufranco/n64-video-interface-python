# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to get something to work
on hardware that stopped being supported before some of us were writing software.

## What is expected

Technical disagreement is welcome and is most of what a project like this is. Take
it to the evidence: run the thing, read the bytes, say what you measured. Several
conclusions in this project's history reversed under measurement, and every one of
them reversed because somebody checked rather than argued.

Assume good faith about mistakes. A wrong patch, a wrong checksum or a wrong claim
is a thing to correct, not a thing to be scored against somebody.

## What is not

Personal attacks, harassment, or making somebody's identity the subject. Deliberate
bad faith: reopening a settled question without new evidence, or arguing a point
already answered by a measurement in the thread.

## Scope

Issues, pull requests, discussions and commit messages on this repository.

## Enforcement

Report through
[GitHub's private vulnerability reporting](https://github.com/gufranco/n64-video-interface-python/security/advisories/new)
or by opening an issue if it does not need to be private. This is a small project
with one maintainer, so the realistic response is that a comment gets removed, or a
person gets blocked, and that is the whole enforcement ladder.
